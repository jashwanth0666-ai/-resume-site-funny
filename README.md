# 🌐 Resume & Bio-data Website

This is a **beginner-friendly multi-page website project** created using **HTML, CSS, JavaScript, and jQuery**.  
The website contains personal **Resume and Bio-data pages** with simple, clean, and attractive styling.  
It is developed as part of a **college programming assignment**.

---

## 📌 Project Features

- ✅ Multi-page website (Home, Resume, Bio-data)
- ✅ Built using:
  - HTML for structure
  - CSS for styling
  - JavaScript & jQuery for interactivity
- ✅ Professional footer design
- ✅ Clean and responsive layout
- ✅ User-friendly navigation
- ✅ Hosted on cloud platform using **GitHub Pages**
